# BlakKat Melrose

Official artist website for BlakKat Melrose — producer and artist working across hip-hop, rap, and underground hip-hop.

## Setup

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Stack

- React 19
- Vite
- Tailwind CSS v4
- GSAP (scroll animations)
- Lenis (smooth scrolling)
